# Komentář k zákonu č. 214/2022 Sb., o zvláštních důvodech pro zastavení exekuce a o změně souvisejících zákonů

Otevřený komentář k zákonu o zvláštních důvodech pro zastavení exekuce — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; dotčené exekuce, postup exekutora, výzva oprávněnému a záloha, zastavení exekuce, náklady a náhrada exekutora, přechodná ustanovení a změny občanského soudního řádu a exekučního řádu.

Konsolidované znění: dokument e-Sbírky `SB-2022-00214_2022-09-01`.
